# Jialu Xu

Personal research and projects website. The public site contains the current
About page, three selected publications, HornSuite, Coécho, and The Pack.

## Local development

```sh
pnpm install --frozen-lockfile
pnpm dev
```

## Deployment

The GitHub Pages workflow builds the site from this repository and publishes
`dist/` whenever `main` is updated; it can also be run manually from the
Actions tab. The hash routes are `#/` and `#/projects`.
